# IDS_Internship26 – IT Help Desk & Ticketing Management System

## Project Overview

The IT Help Desk & Ticketing Management System is a full-stack web application developed as part of a Full Stack Development Internship project. The system is designed to simplify and organize technical support operations within organizations by providing a centralized platform for managing IT support requests.

Employees can submit and track support tickets, while administrators can monitor, assign, prioritize, and resolve issues through an intuitive management interface. The platform improves communication between users and IT personnel by providing structured workflows, ticket tracking, notifications, reporting tools, and analytics dashboards.

This project demonstrates real-world software development practices, including frontend development, backend API design, database management, authentication and authorization, file management, reporting, analytics, and AI-assisted support features.

## Features

* Secure user registration and login
* JWT-based authentication
* Role-based authorization
* Protected application routes

* Create support tickets

* Real-time dashboard statistics

### Attachments & Documentation

* Upload files and supporting documents

### Notifications

* Notification center
* Unread notification tracking

### AI Assistant

* Integrated AI Help Desk Assistant
* Ticket guidance and troubleshooting support
* AI-powered ticket assistance features

### User Profile Management

* Profile management page
* User information updates
